A quick note on the heavier tools

Background removal uses a real on-device model. It needs an initial internet download (about 40 MB plus runtime), enough free memory and a compatible Android WebView. Enable optional internet features to download it. Model execution has not been verified on a physical Android device. The standalone APK does not include the optional speech-recognition server: the Speech tool edits/saves transcripts, while microphone transcription is unavailable. Server synchronization is not included in this standalone edition.

Good to know before you download.

Keep your thoughts safe.

The app lock does not encrypt stored data. Use Android device security and export backups in Settings. Uninstalling or clearing app storage removes your local records. Locking the app keeps them.

Your exports, your choice.

Downloads inside the APK open Android's share sheet. Choose Files or another destination to save them. Updating an APK with the same app ID/signing certificate preserves app data; back up before upgrades.

Built in the open.

Personal OS includes AGPL-3.0 background-removal code. Read the complete source, license and documentation. No paid API or image uploads.

Check your download.

Release metadata & checksums. Package: com.bibacau.personalos. This is a first standalone release; real-device testing remains recommended.
